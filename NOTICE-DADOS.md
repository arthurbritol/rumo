# Aviso sobre dados de terceiros

Dados de radares: Pardal (github.com/murkiriel/pardal), base derivada do OpenStreetMap sob licença ODbL 1.0. © colaboradores do OpenStreetMap. Fontes: DNIT, PRF, ANTT, Inmetro, órgãos estaduais e municipais. A sinalização da via sempre prevalece.

- Pardal: https://github.com/murkiriel/pardal
- OpenStreetMap e licença ODbL: https://www.openstreetmap.org/copyright

O Rumo não republica o banco do Pardal nem do OpenStreetMap: o aplicativo baixa, no aparelho de cada pessoa, os arquivos públicos do Pardal por estado e os guarda só ali, para uso nos avisos de estrada. Nada é hospedado em servidor do Rumo. A atribuição acima também aparece em Perfil > Avisos na estrada > Dados de radares.
