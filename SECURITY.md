# Segurança

Encontrou uma vulnerabilidade? **Não abra uma issue pública.** Use o botão *Report a vulnerability* na aba
*Security* deste repositório (relato privado). Respondo assim que possível.

O app não tem backend: localização, viagens e manutenção ficam apenas no celular. As únicas chamadas de rede
são para os serviços de mapa, rota e busca listados no [README](README.md).
